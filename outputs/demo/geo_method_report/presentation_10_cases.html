Open the slide-style visual deck. The diagrams are also available under presentation/diagrams/.

Use This Framing

Do not use the 360-case run as the main small-object claim. It includes clothing and larger accessories. The quantitative claim should be the 32-case hard small-object set: ring, bracelet, and earrings. The 10 visual cases broaden the explanation to glasses and necklace.

End-to-End Method

Input person image, object image, and object class. Normalize and build the OmniTry conditioning. Add class-specific affordance prompt. Generate K candidates with the frozen pretrained model. Score each candidate with object consistency, person preservation, and artifact health. Select the best candidate and save diagnostics.
